# ছবি দেখা ও অনুমোদন: তোমার সেটআপের জন্য ধাপে ধাপে

তোমার ফর্ম: **"ভোলার ভ্রমণের স্থানের ছবি পাঠান"** · তোমার Sheet: **"ভোলা সেবা - যাচাই"**

## পথটা এক নজরে
```
ইউজার অ্যাপে "📸 ছবি পাঠান" চাপে → নিয়ম পড়ে → ফর্মে ছবি পাঠায়          (চালু আছে)
        ↓
ছবি তোমার Google Drive-এ, উত্তর "ভোলা সেবা - যাচাই" Sheet-এ আসে
        ↓
Sheet মেনু "ভোলা ছবি → ২) ছবি দেখে অনুমোদন করো"
   → উইন্ডোতে ছবি বড় করে দেখাবে (মাপসহ) → [✔ অনুমোদন] [✖ বাতিল] [এড়িয়ে যাও]
        ↓
উইন্ডোর শেষে "প্রকাশের জন্য তৈরি করো" (বা মেনু ৩)
        ↓
GitHub → Actions → "Sync approved photos and spots" → Run workflow
        ↓
অ্যাপের ভ্রমণ-কার্ডে "📷 ছবি দেখুন (১)" → গ্যালারি, নিচে "ছবি: নাম"
```
**তুমি "অনুমোদন" না চাপলে কিছুই অ্যাপে যায় না।**

---

## ক) একবারের সেটআপ (প্রায় ১৫ মিনিট)

### ১. ফর্মের সম্মতি ঠিক করো (এটা না করলে কেউ সম্মতি ছাড়াই ছবি পাঠাতে পারে)
ফর্মের "সম্মতি" প্রশ্নে তিন-ডট (⋮) → **Response validation → Select at least → ৪**। আর তালিকায় "সম্মতি" নামে আলাদা কোনো অপশন থাকলে মুছে দাও (ওটা প্রশ্নের শিরোনাম)।

### ২. ফর্মের উত্তর "ভোলা সেবা - যাচাই" Sheet-এ নাও
ফর্ম → **Responses** → সবুজ **Link to Sheets** → **Select existing spreadsheet** → "ভোলা সেবা - যাচাই"। Sheet-এ নতুন ট্যাব (যেমন "Form Responses 2") আসবে; আগের তথ্য-ফর্মের ট্যাব অক্ষত থাকবে।

### ৩. স্ক্রিপ্ট বসাও (একই Sheet-এ আগের স্ক্রিপ্টের পাশে)
"ভোলা সেবা - যাচাই" Sheet → **Extensions → Apps Script**। বাঁ দিকে ফাইল-তালিকা। প্রতিটির জন্য **+ → Script**, নাম দিয়ে পুরো লেখা পেস্ট:

| ফাইল | কী করবে |
|---|---|
| **FormSetup.gs** | আগেরটার জায়গায় **নতুন সংস্করণ বসাও** (শুধু `onOpen` এর নাম বদলেছে) |
| **PhotoApprove.gs** | নতুন: ছবি দেখা, অনুমোদন, প্রকাশ |
| **Menu.gs** | নতুন: তিন স্ক্রিপ্টের মেনু একসাথে খোলে |
| SpotSetup.gs | (স্পট-প্রস্তাব চালু করতে চাইলে; পরে বসালেও চলবে) |

> ⚠ **FormSetup.gs পুরনোটাই রেখে** নতুন ফাইল বসালে দুটো `onOpen` হয়ে যায়, আর "ভোলা সেবা" মেনু উধাও হয়। তাই FormSetup.gs অবশ্যই নতুনটা দিয়ে বদলাও। এখন সব ফাইল নির্ভয়ে একসাথে থাকতে পারে (নামের সংঘর্ষ নেই; পরীক্ষায় যাচাই করা)।

Save (Ctrl+S) → Sheet রিফ্রেশ (F5)। উপরে মেনু আসবে: **ভোলা সেবা** · **ভোলা ছবি** (· ভোলা স্পট)। প্রথমবার Google অনুমতি চাইবে: "Advanced → Go to … (unsafe) → Allow" (এটা তোমার নিজের স্ক্রিপ্ট)।

### ৪. মেনু "ভোলা ছবি → ১) প্রথমবার সেটআপ"
ছবির ট্যাবে **অবস্থা** (বাছাই-তালিকা) ও **প্রকাশ-অবস্থা** কলাম আর **"প্রকাশিত"** ট্যাব তৈরি হবে।

### ৫. শুধু "প্রকাশিত" ট্যাব ওয়েবে প্রকাশ করো
**File → Share → Publish to web** → বাঁ ড্রপডাউনে **"Entire Document" নয়, "প্রকাশিত"** → ডানে **Comma-separated values (.csv)** → Publish → লিংক কপি।
> ⚠ "Entire Document" দিলে ইমেইলসহ পুরো উত্তর ইন্টারনেটে খোলা হয়ে যাবে। "প্রকাশিত" ট্যাবে ইমেইল **নেই**: শুধু স্থান, ফাইল আইডি, নাম, তারিখ।

### ৬. GitHub-এ লিংক
রিপো → **Settings → Secrets and variables → Actions → New repository secret** → Name `PHOTO_SHEET_CSV_URL`, Secret = ওপরের লিংক। (রিপোতে `sync-photos.yml` push করা থাকতে হবে।)

## খ) ছবি দেখে অনুমোদন (প্রতিদিন)
1. "ভোলা সেবা - যাচাই" Sheet খোলো → মেনু **ভোলা ছবি → ২) ছবি দেখে অনুমোদন করো**।
2. উইন্ডোতে একটি করে অপেক্ষমাণ ছবি আসবে: **স্থানের নাম, কে পাঠিয়েছেন, ছবির মাপ**, আর "বাকি N টি"।
   - **⚠ ছবি ছোট** লেখা এলে (৭০০×৪০০ এর কম) বাতিল করাই ভালো; অ্যাপে ঝাপসা দেখাবে (টুলও এমন ছবি নেয় না)।
   - বড় করে দেখতে "নতুন ট্যাবে বড় করে খোলো"।
3. দেখো:
   - ✔ পরিষ্কার, দিনের আলো, ঝাপসা নয়, ওয়াটারমার্ক নেই
   - ✔ স্থানের নামের সাথে ছবি মেলে
   - ✔ স্পষ্ট মানুষের মুখ নেই (বা অনুমতি আছে), অশোভন নয়
4. **✔ অনুমোদন** / **✖ বাতিল** / **এড়িয়ে যাও** চাপো। পরের ছবি নিজে আসে।
5. সব শেষ হলে উইন্ডো বলবে "আর কোনো অপেক্ষমাণ ছবি নেই" → **প্রকাশের জন্য তৈরি করো** চাপো।
6. GitHub → **Actions → Sync approved photos and spots → Run workflow** (না চাপলে ৬ ঘণ্টায় নিজে চলে)। সবুজ ✔ এলে অ্যাপে তালিকা নিচে টেনে রিফ্রেশ করো। কার্ডে **"📷 ছবি দেখুন (১)"** আসবে।

## গ) ছবি সরানো
Sheet-এ ওই সারির **অবস্থা → সরানো হোক** → মেনু **৩) অনুমোদিত ছবি প্রকাশের জন্য তৈরি করো** → Actions-এ Run workflow। ছবি রিপো ও অ্যাপ থেকে চলে যায়, Drive-এ ফাইল আবার ব্যক্তিগত হয়।
(কেউ নিজের ছবি সরাতে চাইলে তোমার ইমেইলে জানাবেন; গোপনীয়তা নীতিতে লেখা আছে।)

## ঘ) নতুন স্পটে ছবি
স্পট অনুমোদনের পর মেনু **৪) ফর্মের স্থানের তালিকা হালনাগাদ করো** একবার চালাও; ফর্মের ড্রপডাউনে নতুন স্পটের নাম আসবে। (স্ক্রিপ্টের ওপরের `PHOTO_DATA_JSON_URL` তোমার GitHub Pages ঠিকানা হতে হবে; ফর্মের "স্থানের নাম" প্রশ্ন **Dropdown** ধরনের হতে হবে।)

## চ) সমস্যা হলে
| লক্ষণ | কারণ ও সমাধান |
|---|---|
| মেনু আসেনি | Menu.gs বসাওনি, বা Save করে Sheet রিফ্রেশ করোনি |
| "ভোলা সেবা" মেনু নেই | FormSetup.gs পুরনোটাই আছে; নতুনটা দিয়ে বদলাও |
| উইন্ডোতে "ছবি আনা যায়নি" | "নতুন ট্যাবে বড় করে খোলো" চাপো; ফাইল তোমার Drive-এ আছে কিনা দেখো |
| "ছবির কলামসহ উত্তর-ট্যাব পাওয়া যায়নি" | ফর্ম Sheet-এ লিংক করা নেই (ধাপ ক-২) |
| Actions: `PHOTO_SHEET_CSV_URL সেট করা নেই` | ধাপ ক-৬ করা হয়নি |
| `CSV এর প্রথম ঘর "স্থান" নয়` | ভুল ট্যাবের লিংক; "প্রকাশিত" ট্যাব বেছে আবার Publish করো |
| `ছবি নয় (Content-Type…)` | "প্রকাশের জন্য তৈরি করো" চালানো হয়নি, অথবা Drive ফাইল এখনো ব্যক্তিগত |
| `convert.py` এ লাল ✗ "নামে কোনো ভ্রমণের স্থান নেই" | ফর্মের ড্রপডাউনের নাম `data.csv` এর স্থানের নামের সাথে হুবহু মেলেনি |
| অ্যাপে পুরনো তথ্য | অ্যাপে তালিকা নিচে টেনে রিফ্রেশ; GitHub Pages-এ আসতে ১-২ মিনিট লাগে |
