# ভ্রমণের স্থানের ছবি পাঠানোর ফর্ম (একবার বানাতে হবে)

**কেন হাতে বানাতে হবে:** Apps Script দিয়ে ফর্মে ফাইল-আপলোড প্রশ্ন বানানো যায় না। তাই এই ফর্ম Google Forms-এ নিজে বানাও (১০ মিনিট)।
**কেন Google ফর্ম:** আলাদা সার্ভার লাগে না; ছবি তোমার Google Drive-এ জমে; অ্যাপ হালকা থাকে।

## ধাপ ১: ফর্ম বানাও
1. forms.google.com → নতুন ফর্ম। নাম: **"ভোলার ভ্রমণের স্থানের ছবি পাঠান"**।
2. ⚙️ Settings:
   - **Responses → Collect email addresses = Verified** (ইমেইল যাচাই হয়, শুধু তুমি দেখবে)
   - **Responses → Limit to 1 response** ✅ (এক ব্যক্তি একটি ছবি, এটাই "Per user ১টি" নিয়ম। এতে ফর্ম খুলতে Google-এ লগইন লাগে)
   - **Responses → Send responders a copy** বন্ধ রাখো
3. প্রশ্নগুলো এই ক্রমে:
   1. **স্থানের নাম** (Dropdown, বাধ্যতামূলক): `তুলাতুলি`, `ইলিশবাড়ি`, `ইলিশা`, `বোরহানউদ্দিন ইকোপার্ক`, `চর কুকরি-মুকরি`, `জ্যাকব টাওয়ার`, `তারুয়া সৈকত`, `ঢালচর`, `খেজুরগাছিয়া`, `বেতুয়া`, `শেখ রাসেল শিশু পার্ক`, `মনপুরা দ্বীপ` (data.csv এর নামের সাথে **হুবহু মেলাও**)
   2. **ছবি** (File upload, বাধ্যতামূলক): শুধু Image, সর্বোচ্চ **১টি ফাইল**, সর্বোচ্চ ১০ MB
   3. **আপনার নাম** (Short answer, বাধ্যতামূলক): সাহায্য-লেখা: "ছবির নিচে \"ছবি: আপনার নাম\" হিসেবে দেখাবে"
   4. **সম্মতি** (Checkbox, সবগুলো বাধ্যতামূলক):
      - ☑ ছবিটি আমার নিজের তোলা এবং এর স্বত্ব আমার।
      - ☑ ছবিতে কারও মুখ স্পষ্ট নয়, অথবা তাঁদের অনুমতি আমার আছে।
      - ☑ ভোলা অনলাইন সেবা অ্যাপে ছবিটি প্রকাশ করার এবং আমার নাম ছবির সূত্র হিসেবে দেখানোর অনুমতি দিচ্ছি।
      - ☑ আমি জানি ছবি যাচাই করে প্রকাশ হবে, ভালো না হলে প্রকাশ নাও হতে পারে, এবং যেকোনো সময় সরানো হতে পারে।
4. ফর্মের বর্ণনায় লেখো: "ভালো ছবির টিপস: দিনের আলোয় তোলা, আড়াআড়ি (landscape), ঝাপসা নয়, ওয়াটারমার্ক নেই। আপনার ইমেইল কখনো প্রকাশ হবে না।"

## ধাপ ২: অ্যাপে লিংক বসাও
Send → 🔗 লিংক কপি → `strings.xml` এর `photo_form_url` এ বসাও। ফাঁকা থাকলে অ্যাপে "ছবি পাঠান" বাটন লুকানো থাকে।

## ধাপ ৩: সাপ্তাহিক যাচাই ও প্রকাশ
1. ফর্মের Responses → Google Sheet-এ খোলো; ছবি Drive-এ জমে থাকে।
2. ছবি দেখো। **বাদ:** ঝাপসা, ওয়াটারমার্ক, অন্যের ছবি, স্পষ্ট মুখ, অশোভন, স্থানের সাথে মেলে না। বাদ গেলে Drive থেকে মুছে দাও (জায়গা বাঁচবে)।
3. ভালো ছবি ডাউনলোড করে রিপোর ফোল্ডারে:
   ```
   python3 tools/add_photo.py ~/Downloads/ছবি.jpg --place "জ্যাকব টাওয়ার" --slug jacob-tower --credit "ফটোগ্রাফারের নাম"
   git add -A
   git commit -m "Add photo"
   git push
   ```
4. ছবি Drive থেকেও মুছে দিতে পারো (রিপোতে ছোট কপি আছে)।
5. **ইমেইল** শুধু ফর্ম-শীটে থাকবে; `data.csv` বা রিপোতে লিখবে না।

## ছবি সরানো
`python3 tools/add_photo.py --place "জ্যাকব টাওয়ার" --remove jacob-tower-2.jpg` → commit → push। কেউ নিজের ছবি সরাতে চাইলে তোমার ইমেইলে জানাবেন (গোপনীয়তা নীতিতে লেখা আছে)।
