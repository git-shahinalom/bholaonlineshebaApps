# পুশ নোটিফিকেশন ও সাইরেন: সেটআপ গাইড

অ্যাপে Firebase যুক্ত আছে (প্রজেক্ট: `bholaonlineshebaapps`)। বার্তা পাঠানোর জন্য GitHub-কে একটা অনুমতি-চাবি দিতে হবে।

## ১. সার্ভিস-অ্যাকাউন্ট চাবি বানাও (একবার)

1. https://console.firebase.google.com → তোমার প্রজেক্ট খোলো।
2. ⚙ **Project settings → Service accounts** ট্যাব।
3. **Generate new private key** → **Generate key**। একটা `.json` ফাইল ডাউনলোড হবে।

> ⚠ **এই ফাইল পাসওয়ার্ডের মতো গোপন।** কাউকে পাঠিও না, আমাকেও না, GitHub রিপোর ফাইলে বা ছবি/স্ক্রিনশটে রেখো না।
> ভুলে শেয়ার হয়ে গেলে Firebase-এ ওই চাবি **মুছে নতুন বানাও**।

## ২. GitHub Secret-এ বসাও

1. রিপোতে **Settings → Secrets and variables → Actions → New repository secret**।
2. নাম: `FIREBASE_SERVICE_ACCOUNT` (হুবহু এভাবে)।
3. মান: ডাউনলোড করা `.json` ফাইলটা নোটপ্যাডে খুলে **পুরো লেখা** কপি-পেস্ট করো। **Add secret**।
4. এবার পিসি থেকে ডাউনলোড করা ফাইলটা **মুছে ফেলো** (Recycle Bin ও খালি করো)।

## ৩. পরীক্ষা করো

1. ফোনে অ্যাপ ইনস্টল করে একবার খোলো (নোটিফিকেশন-অনুমতি দাও)।
2. GitHub → Actions → **Send test push** → Run workflow।
3. ফোনে "পরীক্ষামূলক বার্তা" নোটিফিকেশন আসলে সব ঠিক। না এলে Actions-এর লাল লেখা আমাকে পাঠাও (Secret-এর কিছু নয়)।
4. এরপর অ্যাপের সতর্কবার্তা পাতায় **"▶ পরীক্ষা"** চেপে সাইরেন শুনে নাও।

## ৪. আসল সতর্কবার্তা পাঠানো

Actions → **Publish alert** → Run workflow:
- **warning** মাত্রা: সবার ফোনে নোটিফিকেশন যায় + অ্যাপে কমলা ব্যানার।
- **severe** মাত্রা (নিশ্চিতকরণ-টিকসহ): নোটিফিকেশন + লাল ব্যানার + **১ মিনিটের সাইরেন**।
- **info** মাত্রা: পুশ যায় না, শুধু অ্যাপের ব্যানারে।
- **clear**: সবার ফোনে সতর্কবার্তা মুছে যায়, সাইরেন থামে।

## ৫. google-services.json এর API key সীমিত করো (নিরাপত্তা)

অ্যাপের `google-services.json` এ একটা API key আছে। এটা সার্ভিস-অ্যাকাউন্ট চাবির মতো গোপন নয়, তবে অন্য কেউ অপব্যবহার না করতে পারে সেজন্য সীমা দেওয়া ভালো:
1. https://console.cloud.google.com → একই প্রজেক্ট → **APIs & Services → Credentials**।
2. ওই API key চাপো → **Application restrictions → Android apps** → প্যাকেজ নাম `com.firojatechsystem.bholaonlineseba` ও অ্যাপের **SHA-1** দাও (Android Studio টার্মিনালে `gradlew signingReport` চালালে SHA-1 পাবে)।
3. Play Store-এ আপলোড করলে Play-র সাইনিং SHA-1-ও যোগ করতে হবে।

## জেনে রাখো: সীমাবদ্ধতা

- সাইরেন বাজে **অ্যালার্ম-ভলিউমে**। ফোন সাইলেন্ট থাকলে বা অ্যালার্ম-ভলিউম শূন্য হলে শব্দ হবে না, অ্যাপ এটা পেরোতে পারে না।
- নোটিফিকেশন-অনুমতি না দিলে ফোনে আগাম খবর যাবে না (অ্যাপ খুললে ব্যানারে দেখাবে)।
- ইন্টারনেট না থাকলে বার্তা পৌঁছাবে না। দ্বীপ-এলাকায় নেটওয়ার্ক দুর্বল হলে দেরি বা না-আসা হতে পারে।
- কিছু ফোনে (শাওমি, ওপো, ভিভো, রিয়েলমি ইত্যাদি) ব্যাটারি-সেভার ব্যাকগ্রাউন্ড অ্যাপ বন্ধ করে দেয়। ইউজারদের অ্যাপের "Battery → Unrestricted / Auto-start চালু" করে নিতে বলো।
- Google Play Services নেই এমন ফোনে পুশ আসে না।
- এটা **সরকারি সতর্কবার্তার বিকল্প নয়, সহায়ক**। ১০৯০, সিপিপি স্বেচ্ছাসেবক ও স্থানীয় প্রশাসনের ঘোষণাই মূল।
- ভুল সতর্কবার্তা বিপজ্জনক। সবসময় আবহাওয়া অধিদপ্তরের সংকেত নিজে যাচাই করে তবেই পাঠাও।
