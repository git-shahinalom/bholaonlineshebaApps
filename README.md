# ভোলা অনলাইন সেবা - ডেটা

এই repository টা **Bhola Online Seba** অ্যাপের ডেটাবেস।
`data.csv` এডিট করলে নিজে নিজে `data.json` তৈরি হয়, আর অ্যাপ সেখান থেকে নতুন তথ্য নেয়।
Play Store এ নতুন ভার্সন দিতে হয় না।

## ফাইলগুলো

| ফাইল | কাজ |
|---|---|
| `data.csv` | **এটাই তুমি এডিট করবে** (Excel এ খোলে) |
| `data.json` | অ্যাপ এটা পড়ে। **হাতে এডিট করো না**, নিজে বানায় |
| `convert.py` | CSV থেকে JSON বানায় ও ভুল ধরে |
| `.github/workflows/build-json.yml` | CSV বদলালেই স্বয়ংক্রিয়ভাবে convert.py চালায় |

---

## একবারের সেটআপ

### ধাপ ১: ফাইল আপলোড
1. Repository র মূল পাতায় **uploading an existing file** লিংকে চাপো।
2. ZIP এর ভেতরের সব কিছু (`data.csv`, `data.json`, `convert.py`, `README.md` এবং **`.github` ফোল্ডার**) টেনে এনে ছাড়ো।
3. নিচে **Commit changes** চাপো।

> `.github` ফোল্ডার আপলোড না হলে (ফোল্ডার দেখা না গেলে): **Add file → Create new file** চেপে নামের ঘরে
> `.github/workflows/build-json.yml` লেখো (স্ল্যাশ দিলে ফোল্ডার নিজে তৈরি হয়), তারপর ফাইলের লেখা কপি-পেস্ট করে Commit করো।

### ধাপ ২: GitHub Pages চালু
1. **Settings → Pages** এ যাও।
2. **Build and deployment → Source: Deploy from a branch** বেছে নাও।
3. **Branch: main**, ফোল্ডার **/ (root)** দিয়ে **Save** চাপো।
4. ১-২ মিনিট পর পাতার উপরে "Your site is live at ..." দেখাবে।

### ধাপ ৩: লিংক পরীক্ষা
ব্রাউজারে এই লিংক খোলো, JSON দেখা গেলে সব ঠিক:

    https://git-shahinalom.github.io/bholaonlineshebaApps/data.json

### ধাপ ৪ (যদি Actions এ লাল ✗ আসে "permission denied")
**Settings → Actions → General → Workflow permissions → Read and write permissions** বেছে Save করো।

## প্রতিদিনের কাজ: তথ্য বদলানো

### পদ্ধতি ক: GitHub এ সরাসরি (ছোট বদল)
1. `data.csv` ফাইল খুলে ✏ (Edit) চাপো।
2. সারি যোগ/বদলাও, তারপর **Commit changes**।

### পদ্ধতি খ: Excel এ (বেশি তথ্য)
1. `data.csv` ডাউনলোড করে Excel এ খোলো।
2. এডিট করো।
3. **Save As → "CSV UTF-8 (Comma delimited)"** বেছে সেভ করো।
   ⚠ শুধু "CSV" বেছো না, বাংলা অক্ষর নষ্ট হয়ে যাবে।
4. GitHub এ **Add file → Upload files** দিয়ে একই নামে আবার আপলোড করো (পুরনোটা বদলে যাবে)।

### তারপর
- **Actions** ট্যাবে সবুজ ✔ এলে সফল। অ্যাপে পৌঁছাতে সাধারণত ২-১০ মিনিট লাগে।
- লাল ✗ এলে ওই এন্ট্রি খুলে দেখো কোন সারিতে কী ভুল, ঠিক করে আবার সেভ করো।
  ভুল থাকলে `data.json` বদলায় না, তাই অ্যাপে পুরনো ঠিক ডেটাই দেখায়।

## data.csv লেখার নিয়ম

কলাম (প্রথম সারি হেডার, মুছো না): **উপজেলা, ক্যাটাগরি, নাম, ঠিকানা, ফোন, নোট, দেখাবে?, নমুনা?, যাচাই তারিখ, অক্ষাংশ, দ্রাঘিমাংশ, ছবি, ছবির সূত্র**
(শেষের ৫টি কলাম ঐচ্ছিক; ফাঁকা রাখলে চলে।)

**উপজেলা:** ভোলা সদর, বোরহানউদ্দিন, চরফ্যাশন, দৌলতখান, লালমোহন, মনপুরা, তজুমদ্দিন, **জাতীয়** (সারা দেশের জরুরি হটলাইনের জন্য)

**ক্যাটাগরি:** হাসপাতাল, এ্যাম্বুলেন্স, পুলিশ, আইনজীবী, ভ্রমণের স্থান, ইউনিয়ন পরিষদ, জরুরি বিদ্যুৎ, রেন্ট-এ-কার, ফায়ার সার্ভিস, **হটলাইন** (শুধু "জাতীয়" উপজেলার সাথে)

এখন **প্রতিটা উপজেলায় ৯টি ক্যাটাগরির কার্ডই** অ্যাপে আছে। কোনো ক্যাটাগরিতে তথ্য না থাকলে "শীঘ্রই আসছে" দেখায়।
"জাতীয়" উপজেলায় শুধু "হটলাইন" ক্যাটাগরি চলে।

**নাম:** বাধ্যতামূলক। ফাঁকা থাকলে সারিটা বাদ যায়।
**ঠিকানা, নোট:** ঐচ্ছিক।
**ফোন:** একটা নম্বর। দুটো নম্বর দিতে চাইলে আলাদা সারি করো। Excel শুরুর `0` কেটে দিলেও নিজে ঠিক করে নেয়।
**যাচাই তারিখ:** `2026-10-05` ফরম্যাটে লিখলে অ্যাপে "✔ যাচাইকৃত · তারিখ" ব্যাজ আসে। ফোন করে যাচাই করার পরই লেখো।
**অক্ষাংশ, দ্রাঘিমাংশ:** (ভ্রমণের স্থানের জন্য) Google Maps-এ স্থানটা ধরে রাখলে ওপরে সংখ্যা দেখায়, যেমন `21.925583, 90.647056`। অক্ষাংশ আগে, দ্রাঘিমাংশ পরে। এগুলো দিলে অ্যাপে "ম্যাপে দেখুন", "রাস্তা দেখান" ও দূরত্ব আসে। ভোলার বাইরের মান দিলে কনভার্টার আটকে দেয়।
**ছবি, ছবির সূত্র:** `images/` ফোল্ডারের ফাইলের নাম (একাধিক হলে `|` দিয়ে), আর ফটোগ্রাফারের নাম। নিয়ম `images/README.md` তে।
**নমুনা?:** `হ্যাঁ` লিখলে সারিটা অ্যাপে "🔸 নমুনা তথ্য" ব্যাজসহ দেখায়, কল/সেভ/শেয়ার বাটন থাকে না এবং খোঁজার ফলে আসে না।
নমুনা সারিতে **ফোন নম্বর রাখা যায় না** (কনভার্টার আটকে দেয়), যাতে কেউ ভুল নম্বরে কল না করে।
আসল তথ্য জোগাড় হলে নমুনা সারি মুছে দাও। Excel এ `নমুনা?` কলামে ফিল্টার দিয়ে সব `হ্যাঁ` সারি একবারে মুছতে পারবে।
**দেখাবে?:** `না` লিখলে সারি মুছে ফেলা ছাড়াই লুকানো থাকে। ফাঁকা বা `হ্যাঁ` মানে দেখাবে।
**ক্রম:** সারির ক্রমই অ্যাপে তালিকার ক্রম।

**ইউনিয়নের তালিকা:** ভোলা সদর (১৩), লালমোহন (৯), চরফ্যাশন (১৯), মনপুরা (৪) সম্পূর্ণ (উইকিপিডিয়া ও সরকারি সূত্রে মিলিয়েছি)। বাকিগুলো নমুনা:
- বোরহানউদ্দিন, দৌলতখান, তজুমদ্দিন: সূত্রগুলো একে অপরের সাথে মেলে না, তাই নমুনা সারি আছে।

> সরকারি সাইটের তথ্যও পুরনো হতে পারে। নতুন কোনো নম্বর বসানোর আগে একবার ফোন করে নিশ্চিত হও,
> আর মাঝে মাঝে সবগুলো নম্বর আবার যাচাই করো।

## আবহাওয়া ও সতর্কবার্তা (live ব্রাঞ্চ)

অ্যাপের মূল স্ক্রিনের আবহাওয়া কার্ড ও লাল সতর্কবার্তা ব্যানার `live` নামের আলাদা ব্রাঞ্চ থেকে আসে।
এই ব্রাঞ্চে সবসময় মাত্র ১টা কমিট থাকে এবং `main` ব্রাঞ্চের সাথে কোনো সংঘাত হয় না।

| ফাইল (live ব্রাঞ্চে) | কে বানায় | কখন |
|---|---|---|
| `weather.json` | `Update weather` workflow (Open-Meteo থেকে) | প্রতি ৩০ মিনিটে নিজে নিজে |
| `alerts.json` | `Publish alert` workflow | তুমি যখন চালাও |

**প্রথমবার:** Actions → **Update weather** → **Run workflow** চাপো। সবুজ ✔ এলে এই লিংক খুলে দেখো JSON আসছে কিনা:
`https://raw.githubusercontent.com/git-shahinalom/bholaonlineshebaApps/live/weather.json`

### সতর্কবার্তা পাঠানোর নিয়ম

1. আবহাওয়া অধিদপ্তরের (BMD) সংকেত বা সরকারি নির্দেশনা **নিজে যাচাই করো**।
2. Actions → **Publish alert** → **Run workflow**।
3. পূরণ করো: মাত্রা, বিপদের ধরন, কখন থেকে (যেমন "আজ রাত ১০টা থেকে"), সংকেত (ঐচ্ছিক), মেয়াদ (১-৭২ ঘণ্টা)।
4. **ভয়াবহ (severe)** মাত্রায় "আমি সরকারি সংকেত যাচাই করেছি" টিক দিতেই হবে, নইলে workflow আটকে দেয়।
5. অ্যাপে ৫-১০ মিনিটের মধ্যে লাল ব্যানার দেখাবে (মেয়াদ শেষে নিজে সরে যাবে)।
6. ভুল হলে বা বিপদ কেটে গেলে: **action = clear** দিয়ে চালাও।

বার্তার ছাঁচ: "প্রাণপ্রিয় ভোলাবাসিগণ ... সৃষ্টিকর্তার পরীক্ষা স্বরূপ- **[কখন + বিপদ + হবে/থাকবে]**" (ব্র্যাকেটের অংশ লাল)।
`তাপদাহ` এর ক্ষেত্রে "থাকবে", বাকিগুলোতে "হবে" নিজে বসে যায়।

> ⚠ আবহাওয়া কার্ডের হলুদ "অটো-হিসাব" শুধু কম্পিউটার-মডেলের অনুমান। এটি থেকে কখনো সতর্কবার্তা বা অ্যালার্ম তৈরি হয় না।
> সরকারি সতর্কবার্তা শুধু তুমি যাচাই করে প্রকাশ করলেই যায়।

### জেনে রাখো
